Sources & caveats:
  • Jade names, effects, locations — game-checklists.com/nine-sols/jades/ (curled directly; fetched successfully, archived copy also available at web.archive.org, 2026-10-06). States 28 Jades total, each costing 1-3 Computing Power, base 2 Computing Power expandable to 10 via Computing Units.
  • Jade Computing Power costs — Steam Community forum post "Jades Tier List - Edited" (author "Anderson", posted 2024-09-09, later edited). This is a single player's opinion/analysis post, not an official or wiki source — it is the only place Gate 2 found a per-Jade cost figure. The post's own numeric caveat ("some of them are estimates") refers to damage/percentage figures in its commentary, not to the Computing Power costs, which read off the in-game slot UI. Tier rankings (Good/Useful/Niche/Bad) from that post are NOT reproduced here.
  • Computing Unit price/location — ginx.tv/en/nine-sols/jade-slots, "How To Get More Jade Slots In Nine Sols" by Shane Moosa, last updated August 15, 2024. Live fetch of this exact URL redirected to a generic site hub with no article content; the article text used here came from an archived snapshot, 2026-04-16. Only the first Computing Unit (from the merchant Chiyou, 1,000 Jin) is given a specific price; the article says more exist "throughout the world" and from "other merchants" without naming them.
  • No wiki.gg, Fandom, Fextralife page, or Jade/loadout calculator was found for Nine Sols at time of writing (Gate 2: 3 WebSearches + 2 curls). gameskinny.com's two Jade guide pages returned a Cloudflare challenge page on direct fetch and have no Wayback snapshot, so they could not be used as sources here.
  • Game version/date context: none of the sources above state a specific game-version number; all post-date the game's original early-access/launch window (the Steam post is dated 2024-09-09, the ginx.tv article "last updated" 2024-08-15, the game-checklists.com page undated but archived 2026-10-06).
